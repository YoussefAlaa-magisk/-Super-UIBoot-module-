SuperUI

SuperUI is a custom ROM project based on OneUI, created by Youssef Alaa. SuperUI Boot extends the project with a dedicated Magisk module for rooted OneUI devices.

Boot Experience

SuperUI Boot targets a faster boot experience. The first boot after installing the Magisk module may take around one minute. Subsequent boots are targeted to be faster.
